Desktop Control Using an Enhanced USB Mouse Interface

Open-hardware, high-performance gaming and productivity computer mouse.

RP2040 / C++ Hardware Design PMW3360 Optical Sensor USB Stack Ergonomics Research

My Bachelor's Thesis investigates the biomechanical and technical feasibility of integrating a thumbstick into a precision mouse chassis to offload directional movement from the keyboard hand. While iterative prototyping determined that biomechanical coupling between the thumb and wrist renders simultaneous dual-analog input impractical for high-precision tasks, the project successfully produced a fully operational, professional-grade open-source mouse platform. Engineered to match commercial esports peripherals, the resulting device pairs high-tier optical tracking with robust hardware protection and modular embedded architecture, serving as an unlocked development platform for human-computer interaction research.

Highlights

  • Custom Hardware and Carrier PCB: Designed a carrier board interfacing a Raspberry Pi Pico (RP2040) with a PixArt PMW3360 optical sensor, incorporating dedicated ESD protection circuits and an integrated RGB status-feedback system.
  • Low-Latency Embedded Firmware: Developed high-throughput C/C++ firmware leveraging TinyUSB to achieve a 1000 Hz USB polling rate, configurable contact switch debouncing (1 ms to 20 ms), and profile selection routines.
  • Biomechanical and Ergonomic Research: Conducted empirical usability testing on dual-input chassis prototypes, producing an ergonomic case study documenting how thumb stabilization constraints limit multi-surface mouse controls.
  • Modular Platform Expansion: Engineered a fully unlocked hardware architecture featuring broken-out GPIOs, 3 unallocated ADC channels, an I2C/Stemma expansion footprint, and a socketed MCU structure for future revisions.

2-Bit Arithmetic-Logic Unit

74-Series Logic Logisim KiCad Digital Systems PCB Design

Prototyped in Logisim and routed in KiCad, this project implements a 4-operation ALU executing Addition, Subtraction, AND, and OR functions. The design uses discrete multiplexers and logic gates to demonstrate fundamental CPU component engineering and timing hazard resolution.

Highlights

  • Carry-Lookahead Adder: Engineered a 2-bit CLA to evaluate carry bits simultaneously, eliminating propagation delay race conditions inherent to asynchronous ripple-carry adders.
  • Two's Complement Subtraction: Implemented hardware subtraction by multiplexing inverted inputs and dynamically routing the instruction opcode bit as a +1 carry-in offset.
  • Instruction Multiplexing: Built a dual-stage 2-bit opcode decoder to route combinatorial gate outputs to a 3-bit LED display with dedicated addition overflow detection.
  • Complete EDA Workflow: Validated signal propagation and timing hazards in Logisim Evolution before designing the KiCad schematics and custom PCB layout.

Monte Carlo Analysis of a BJT Memory Cell

LTspice case study analyzing parameter distribution and reliability limits in a bipolar transistor memory cell.

LTspice Monte Carlo Simulation BJT Memory Analog Circuit Design Semiconductor Reliability

This engineering case study investigates a cross-coupled bipolar storage cell built using BCX19 NPN transistors and temperature-variant active loads. By combining operating point, AC small-signal, and transient Monte Carlo simulations, the research evaluates how ±10% transistor gain variations impact circuit stability, time constants, and transient settling times across thermal extremes.

Highlights

  • Monte Carlo Parameter Variance: Modeled a ±10% normal distribution on transistor gain in LTspice to quantify manufacturing imperfection impacts on node voltage dispersions and metastable state convergence.
  • Feedback Impedance and Time Constants: Derived analytical expressions for low-frequency dominant time constants, incorporating Miller capacitance effects and loop-gain feedback mechanics into the equivalent resistance.
  • Transient Settling Analysis: Evaluated transient step-response waveforms across thermal corners (0°C, 27°C, and 85°C), determining precise 90% settling time boundaries.
  • Device Reliability Insights: Demonstrated how component variance forces metastable states to bifurcate into distinct binary output rails, highlighting fault-tolerance vulnerabilities in discrete bipolar storage topologies.
